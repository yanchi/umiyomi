# Contract: Web 画面と URL

**Feature**: 001-marine-forecast-view | **Date**: 2026-10-05

UMIYOMI が利用者に公開するインターフェースは HTML 画面だけ（JSON API は MVP の範囲外。原則 I）。
画面・URL 設計は人間のレビュー対象。

## ルート一覧

| Method | Path | Route 名 | Controller | 用途 |
|---|---|---|---|---|
| GET | `/` | `app_home` | `HomeController` | トップ画面。緯度・経度の入力フォームだけを表示する |
| GET | `/forecast` | `app_forecast` | `ForecastController` | 予報画面。クエリの地点の予報を表示する |

- フォームは `GET /forecast` へ送信する。予報画面の URL がそのまま地点を表し、ブックマーク・再読み込み・別タブで同じ地点を開ける（FR-015）
- POST は使わない（再読み込み時の再送信確認を出さないため。状態を変更する操作もない）

## `GET /forecast`

### Query

| パラメータ | 必須 | 形式 | 例 |
|---|---|---|---|
| `lat` | ○ | 十進数の緯度。全角数字・前後の空白は受け付ける（research R7） | `27.75` |
| `lon` | ○ | 十進数の経度。同上 | `129.05` |

- 入力された文字列はそのまま URL に残る（正規化した URL へのリダイレクトはしない）。同一地点の判定は小数点以下 2 桁に丸めた値で行うので、`27.75` と `27.7500` は同じキャッシュを使う
- **変更（003-coordinate-input-support）**：入力が有効で、入力欄の文字列が正規形（小数点以下 2 桁の十進数。例：`27.75`）でないときは、予報を取得せずに正規形の URL へ **303 リダイレクト**する（`27.7500` → `27.75`、度分・度分秒・1 行の「緯度, 経度」も同様）。正規形の URL ではリダイレクトしない。入力エラー（422）は従来どおり入力した文字列を入力欄に残す。詳細は [specs/003-coordinate-input-support/contracts/web-ui.md](../../003-coordinate-input-support/contracts/web-ui.md)
- 未知のパラメータは無視する

### Response

すべて `Content-Type: text/html; charset=UTF-8`。どの状態でも入力フォーム（入力値入り）を表示する。

| 状況 | Status | 本文 |
|---|---|---|
| 予報を表示（新規取得・再利用） | 200 | 地点、最終更新（再取得時刻付き）、安全の注意書き、時間別の一覧 |
| 前回の予報を代替表示（取得失敗、24 時間以内の前回あり） | 200 | 一覧より目立つ警告、地点、最終更新、注意書き、現在時刻以降の一覧 |
| 入力エラー（未入力・形式不正・範囲外） | 422 | 項目ごとのエラーメッセージ。一覧なし |
| 取得失敗（24 時間以内の前回なし） | 503 | 取得できなかった旨と再試行の案内。一覧なし |
| 問い合わせ回数の上限超過 | 429 | 「しばらく待ってから再度お試しください」。一覧なし |

- 200 以外でも HTML を返すので、ブラウザでは常にフォーム付きの画面が表示される。ステータスコードは、
  Functional Test での判定と、将来のアクセスログでの集計のために状態ごとに分ける
- 429 には `Retry-After` を付けない（sliding window のため正確な秒数を出しにくく、画面の文言で十分なため）
- `Cache-Control` は Symfony の既定（`no-cache, private`）のまま。ブラウザや中間キャッシュが古い予報を「最新」として返さないようにする

## 画面の構成（予報画面、上から順）

1. タイトル「UMIYOMI」と入力フォーム（緯度・経度・「予報を表示」ボタン）
2. 警告（Stale / Unavailable / RateLimited のとき）
3. 地点：`北緯 27.75° / 東経 129.05°`
4. `最終更新：2026/10/05 20:15（21:15以降に再取得）`
5. 安全の注意書き：「この予報は航海の安全を保証するものではありません。出航前に気象庁などが発表する警報・注意報もあわせて確認してください。」
6. 項目グループのメッセージ（波・うねりが得られない等）
7. 時間別の一覧（行＝項目、列＝時刻。項目名の列は左端に固定し、一覧だけ横スクロール）
8. フッター：Open-Meteo の帰属表示（`Weather data by Open-Meteo.com` へのリンク。research R1）

## 文言の制約

- 「安全です」「出航できます」「問題ありません」のような安全・出航可否の断定を含めない（FR-010、原則 IV）
- 傾向の要約（「12時以降、波高が上昇する予報です」）はこの機能では出さない（spec Assumptions）
