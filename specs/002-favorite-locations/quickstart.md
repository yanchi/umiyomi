# Quickstart: お気に入り地点の保存と呼び出し

**Feature**: 002-favorite-locations | **Date**: 2026-10-05

コマンドはリポジトリ直下で実行する。

## 自動テスト

```sh
docker compose build php                         # 開発用イメージに nodejs を追加したあと 1 回だけ
docker compose up -d
docker compose exec php composer test:js         # お気に入りの規則（node --test）
docker compose exec php composer test            # PHPUnit（ViewModel・Functional）
docker compose exec php composer check           # すべて（作業完了前に必ず通す）
```

## ブラウザでの確認

http://localhost:8000 を開く。DevTools の Application → Local Storage → `http://localhost:8000` の `umiyomi.favorites` で中身を確認できる。

### US1：保存して開き直す

1. トップ画面に「お気に入りはまだありません。予報画面で表示中の地点を保存できます。」と、端末内保存の注意書きが出る
2. 緯度 `27.75`・経度 `129.05` で予報を表示し、名前「テスト沖」で保存 →「お気に入りに保存しました」と「お気に入りに保存済み：テスト沖」が出る
3. 予報画面の「お気に入り（1 件）」を開くと「テスト沖」に「表示中」が付いている
4. 緯度 `28.10`・経度 `129.30` で予報を表示し、名前を空欄のまま保存 → 名前が「28.10, 129.30」になる
5. ブラウザを閉じて開き直し、トップ画面の一覧が「28.10, 129.30」「テスト沖」の順で出る
6. 「テスト沖」を選ぶと `/forecast?lat=27.75&lon=129.05` が開く
7. 予報画面の折りたたみ一覧から「28.10, 129.30」を選ぶと、トップ画面を経由せずにその地点に切り替わる
8. `/forecast?lat=27.7549&lon=129.0501` を開くと「保存済み：テスト沖」になる（丸めた座標で同一判定）

### US2・US3：削除と名前変更

1. トップ画面で「28.10, 129.30」の「名前を変更」→「北の瀬」→ 保存。並び順は変わらない
2. 「テスト沖」の「削除」→ 確認ダイアログでキャンセル → 残る。もう一度「削除」→ OK → 消える。再読み込みしても戻らない
3. 「北の瀬」の予報画面で「お気に入りから外す」→ 確認 → OK →「未保存」の表示（名前の入力欄）に戻る

### エッジケース

| 確認すること | 手順 | 期待 |
|---|---|---|
| 名前の上限 | 31 文字の名前で保存 | 保存されず「名前は 30 文字以内で入力してください」 |
| 前後の空白 | 名前「　テスト沖　」で保存 | 「テスト沖」で保存される |
| 名前の表示 | 名前 `<b>x</b>"&'` で保存 | 一覧・保存パネルとも入力したとおりの文字で表示され、太字にならない |
| 名前の重複 | 別の地点に同じ名前で保存 | 保存できる |
| 件数の上限 | DevTools のコンソールで 20 件分の JSON を `umiyomi.favorites` に入れて再読み込みし、未保存の地点で保存 | 保存されず、削除を促す案内 |
| 壊れたデータ | `items` の 1 件を `{"latitude":"x"}` に書き換えて再読み込み | 残りの項目だけが表示され、画面は崩れない |
| JSON 全体が壊れている | 値を `{` にして再読み込み | 「お気に入りはまだありません」。予報は表示できる |
| 取得失敗・回数制限でも保存 | `.env.local` の `OPEN_METEO_MARINE_URL` を到達しない URL にし、未取得の地点を開く（503） | 保存パネルが出て保存できる |
| 入力エラー | `/forecast?lat=95&lon=129.05`（422） | 保存パネルが出ない。折りたたみ一覧は出る |
| localStorage が使えない | Firefox の設定で Cookie とサイトデータをブロック（または Safari のプライベートブラウズ） | お気に入りの枠に「この環境ではお気に入りを保存・表示できません…」。予報は表示できる |
| JavaScript 無効 | DevTools で JavaScript を無効化 | `<noscript>` の文言が出る。予報は表示できる |
| 複数タブ | タブ A・B で同じ地点の予報を開き、A で保存 → B で別名で保存 | B は保存せず保存済みの表示に切り替わる（重複しない） |
| サーバーへの送信なし | DevTools の Network を記録しながら保存・名前変更・削除 | 通信が 0 件。予報画面を開くリクエストに名前が含まれない（SC-006） |

### スマホ幅（FR-015 / SC-005）

DevTools のデバイスモードで幅 360px にし、お気に入りを 20 件入れた状態で、トップ画面の一覧（名前変更の入力欄を開いた状態を含む）と、
予報画面の折りたたみ一覧・保存パネルでページ全体が横にはみ出さないこと、30 文字の名前が折り返して表示されることを確認する。
